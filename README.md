# 🎨 悠悠の个人主页

一个功能丰富的个人主页系统，包含后台管理、日程管理、外链管理等模块。

## ✨ 功能特性

### 前台展示
- 🖼️ **随机二次元图片** - 自动切换多个 API 源
- 👤 **QQ 信息展示** - 自动获取 QQ 头像、昵称、个性签名
- 🏷️ **个人标签** - 展示兴趣标签
- 🔗 **外链入口** - 社交媒体和项目链接
- 📅 **日程提醒** - 实时显示当前课程/日程
- 🎭 **Sakana 挂件** - 千束 & 泷奈桌面宠物

### 后台管理
访问 `/admin` 路径进入管理后台：
- 🏠 **网站信息** - 修改标题、昵称、简介
- 🔌 **API 管理** - 启用/禁用图片 API
- 🏷️ **标签管理** - 添加/删除个人标签
- 🔗 **外链管理** - 自定义社交链接
- 📅 **日程管理** - 课程表 & 个人日程安排

## 🚀 快速开始

### 1. 安装依赖
```bash
cd backend
npm install
```

### 2. 启动服务
```bash
npm start
```

### 3. 访问页面
- 前台页面：http://localhost:3000
- 后台管理：http://localhost:3000/admin

## ⚙️ 配置说明

所有配置通过后台管理界面修改，数据存储在 `backend/data/config.json`。

### 日程类型
- `course` - 课程
- `hobby` - 兴趣爱好
- `project` - 项目开发
- `study` - 学习
- `other` - 其他

### Sakana 角色
- `chisato` - 千束 (右下)
- `takina` - 泷奈 (左下)

- **前端**：原生 HTML/CSS/JS
- **后端**：Node.js + Express
- **数据**：JSON 文件存储
- **挂件**：Sakana Widget
